What crates are

  • Cosmetics only Crates hold cosmetics only. Nothing in a crate helps you win.
  • Earned by playing You can also earn crates by playing.
  • Duplicates Duplicates give back a few Sapphires, which only buy cosmetics.
  • Opened in game Crates are opened in game with /crates.

Connect to the server

  1. Open Minecraft: Java Edition and go to Multiplayer.
  2. Click Add Server and enter
  3. Join, and accept the resource pack. It carries the kits, crests and goals, so the server needs it.
  4. Walk into a pitch's ready zone and the match starts itself.
