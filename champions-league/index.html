      Connect to the server

      1. Open Minecraft: Java Edition 1.21.4 or newer and go to Multiplayer.
      2. Click Add Server and enter
      3. Join, and accept the resource pack. It carries the kits, crests and goals, so the server needs it.
      4. Walk into a pitch's ready zone and the match starts itself.
